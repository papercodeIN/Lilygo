## Overview

This folder contains projects for the LILYGO T4 V1.3, based on the classic ESP32. The T4 product family has display-size variants; the projects below document the configuration they target. Verify your board revision and display before using a project.

## Projects

| Project | Description | Status |
|---|---|---|
| [ESP32 NAS](<Project/ESP32_NAS/README.md>) | microSD web file manager with Wi-Fi setup, status display, and OTA support | PlatformIO project; targets the 2.4-inch display configuration |
| [Bluetooth MP3 Player](<Project/Bluetooth_MP3_Player/README.md>) | Plays MP3 files from microSD and streams audio to Bluetooth devices using A2DP | Hardware-tested project; see README for build steps and limitations |
